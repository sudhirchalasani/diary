📅 Daily Notes

Words match in any order. Use "quotes" for an exact phrase. #tags work too. Pick a Section to search only that part of each day — with no words, it lists every note in that section. Matching days are outlined red on the calendar.

⚙️ Settings

Opens the share menu — choose Drive to save it there.

📥 Import (restore)

Load a backup file from Drive or your phone. You'll be asked before anything is replaced.

🏷️ Sections

These are the buttons above the writing box. Prompts are optional starter lines (one per line) added when you start that section for the day.

Renaming a section keeps old notes findable under the new name. Deleting one keeps its old notes, but they won't show under a Section filter.

📄 Readable copy

All entries as a plain text file you can read anywhere. Can't be imported back — use Export backup for that.
